# Human-like Behavior System - Полная переработка проекта

## Что было сделано

### ❌ Старая система (GPT 5.6 sol)
- Жёсткие шаблонные фразы: "Понял", "Иду", "Готово"
- Роботизированные движения
- Мгновенные реакции на всё
- Автоматическое сообщение координат
- Боты как слуги, ждут команд
- Нет ошибок, нет несовершенств
- Всегда активны, никогда не устают
- Спамят каждую находку в чат

### ✅ Новая система

## Созданные модули (8 файлов)

### 1. **ResponseGenerator** (`response-generator.js`)
Убраны все шаблоны. Теперь каждый ответ уникален и генерируется через LLM с учётом:
- Контекста (здоровье, позиция, настроение)
- Личности бота
- Недавних ответов (избегает повторов)
- Текущей ситуации

### 2. **ProbabilisticReactions** (`probabilistic-reactions.js`)
Боты реагируют вероятностно:
- Нашли алмазы: 30% сразу, 40% потом, 30% молчат
- Отложенные упоминания через 5-60 минут
- Зависит от настроения, болтливости, занятости
- 25+ типов событий с разными вероятностями

### 3. **TypingSimulator** (`typing-simulator.js`)
Имитация человеческой печати:
- Разная скорость для каждого бота (180-300 символов/мин)
- Опечатки с учётом русской раскладки
- Исправления через "*слово"
- 5% шанс отвлечься и не отправить
- Естественные задержки

### 4. **MoodSystem** (`mood-system.js`)
Динамическая система настроений:
- 9 состояний: excited, tired, exhausted, bored, scared, nervous, content, interested, neutral
- Усталость растёт со временем игры
- Скука от однообразия
- Страх от опасности
- Модификаторы поведения на основе настроения

### 5. **PersonalGoalsSystem** (`personal-goals.js`)
Личные цели и инициатива:
- Боты сами придумывают цели на основе интересов
- Предлагают идеи группе
- Могут не согласиться с предложением
- Споры и обсуждения
- 6 типов интересов, 20+ вариантов целей

### 6. **HumanImperfections** (`human-imperfections.js`)
Человеческие ошибки:
- Забывают вещи (3-15% шанс в зависимости от усталости)
- Вспоминают через время
- Прокрастинация (10-35% отложить дело)
- Отвлечения (8% + зависит от интереса)
- Неоптимальные решения (15-40%)
- Реакции на собственные ошибки

### 7. **AFKSystem** (`afk-system.js`)
Случайные перерывы:
- 8 причин AFK (туалет, попить, поесть, телефон, дверь, и т.д.)
- Длительность 1-30 минут
- 50% объявляют, 50% просто "афк"
- Иногда возвращаются позже
- Иногда задерживаются

### 8. **HumanBehaviorController** (`human-behavior-controller.js`)
Главный координатор всех систем:
- Периодическое обновление (30 сек)
- Обработка команд игрока
- Обработка игровых событий
- Проверка инициативы
- Интеграция всех подсистем

## Примеры поведения

### Команды игрока

**До:**
```
Player: иди сюда
Bot: Иду к тебе.
```

**После:**
```
Player: иди сюда
Bot: щас иду
или
Bot: окей
или
Bot: иуд
Bot: *иду
```

### Находки

**До:**
```
*Нашёл алмазы*
Bot: Нашёл алмазы! X: 12, Y: 11, Z: -45
```

**После:**
```
*Нашёл 4 алмаза*
30% шанс:
  Bot: блин алмазы!
  
40% шанс:
  *молчит*
  *через 20 минут*
  Bot: кстати нашел 4 алмаза недавно
  
30% шанс:
  *вообще ничего не говорит*
```

### Местоположение

**До:**
```
Player: где ты?
Bot: Я на координатах [X: 123, Y: 64, Z: 456]!
```

**После:**
```
Player: где ты?
Bot: я на западе от базы
или
Bot: глубоко в пещере
или
Bot: тут рядом
```

### Инициатива

**До:**
```
*Боты молчат и ждут команд*
```

**После:**
```
*Через 15 минут*
Bot: слушайте, давайте в незер сходим или куда-то
или
Bot: че сидим? может пошли алмазы копать
или
Bot: устал я чет, может афк на минут 10?
```

## Интеграция

### Быстрый старт

```javascript
import { HumanBehaviorController } from './behavior/human-like/index.js';

// Для каждого агента
const humanBehavior = new HumanBehaviorController(profile, aiBrain, memoryManager);
humanBehavior.start();

// При команде игрока
const result = await humanBehavior.handlePlayerCommand(intent, message, context);

// При игровом событии
await humanBehavior.handleGameEvent('found_diamonds', { count: 3 });
```

Полная документация: `src/behavior/human-like/README.md`

Пример интеграции: `src/behavior/human-like/integration-example.js`
